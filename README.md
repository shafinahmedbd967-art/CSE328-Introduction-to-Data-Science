## 🎯 Overview

This repository is a structured collection of everything I studied, submitted, and prepared throughout the semester for **CSE328: Introduction to Data Science** — the course that introduces the full data science pipeline, from raw data to meaningful insight. This repository holds assignments, presentations, and midterm/final exam materials, all organized in one place for easy review and future reference.

---

## 📚 Course Overview

**CSE328 — Introduction to Data Science** introduces the foundational concepts, tools, and workflow used to extract insights from data — bridging statistics, programming, and visualization into a single practical skill set.

Key areas covered in this course include:

- Data collection and data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization techniques
- Statistics for data science
- Machine learning basics
- Python for data science (NumPy, Pandas, Matplotlib)

## 🔍 Topics Covered

- **Data Collection & Cleaning** — gathering raw data and preparing it for analysis
- **Exploratory Data Analysis (EDA)** — understanding data through summary statistics and visual exploration
- **Data Visualization** — representing data patterns and trends through charts and graphs
- **Statistics for Data Science** — the statistical foundations behind data-driven decision making
- **Machine Learning Basics** — an introduction to predictive modeling concepts
- **Python for Data Science** — using NumPy, Pandas, and Matplotlib for data manipulation and visualization
